请你编写一个简单的Astrbot插件，以实现将Onebot平台的markdown消息转发到QQ官方bot的功能。
# 要求
## 1. 插件功能
1. 提供命令绑定onebot与qqbot2个平台适配器之间的转发关系
2. 使用正则表达式和/或消息长度检测方法在消息即将发送前检测源消息是否为markdown格式
3. 如果是markdown格式，则将其转发到qqbot平台发送，并且拦截onebot消息发送，否则忽略转发并由onebot端直接发送
4. 允许多对一、一对多绑定关系
## 2. 指令组
总指令组：ob2qb（仅管理员可操作）
    1. 发出绑定指令：req_bind
        - 功能：发出绑定onebot与qqbot平台的适配器的请求，仅限onebot端发出。使用4位随机数字码作为绑定请求唯一标识。
    2. 接收绑定指令：ack_bind
        - 功能：接收绑定请求并确认绑定关系，仅限qqbot端接收。
        - 参数：唯一标识：确认指定的绑定请求。完成后生成并返回6位随机数字码作为绑定关系唯一标识。
    3. 查看绑定关系指令：list_bind
        - 功能：查看当前onebot与qqbot平台的绑定关系及其绑定id。
    4. 解绑指令：unbind
        - 功能：解除onebot与qqbot平台的绑定关系。
        - 参数：唯一标识：解除指定的绑定关系。
## 3. webui设置
采用astrbot标准webui schema文件进行设置，包含markdown匹配表达式等自定义选项
## 4. 插件metadata
需要参照Astrbot插件metadata标准，包含插件名称、版本、作者（Mr. Tim）、描述等中文信息。
# 开发要求
1. 使用Python语言进行开发，确保代码结构清晰，易于维护。
2. 不要出现单文件长代码的情况，请将代码拆分为多个模块，每个模块负责不同的功能。如果模块多可以使用子文件夹管理。
3. 代码中添加必要的中文注释说明函数功能及关键逻辑
4. 参考Astrbot插件开发文档https://docs.astrbot.app/dev/star/plugin-new.html，确保插件符合Astrbot的开发规范和最佳实践。
5. 注意插件效率、实现效率与进度管理，以使插件在没有多余代码的情况下高效运行。
